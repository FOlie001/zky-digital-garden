if (!(cin >> n)) return 0;
**防御性编程（或输入校验）**。
在本地运行代码时，可能手动输入数据。
 但在很多在线评测系统中，如果输入文件为空，或者数据格式不对（比如题目说输入数字，却给了字母），`cin >> n` 会读取失败，并返回一个 `false`。
 如果没有这一句，`n` 将会是一个随机的垃圾值（比如 `4213542`），接下来 `vector<int> a(n)` 就会尝试向系统申请极其庞大的内存，直接导致程序崩溃（RE）或异常退出。
加上这一句，一旦读取失败，程序直接 `return 0` 安全退出。

setw()是C++标准库<iomanip>中的流操纵器，用来设置下一次格式化输出(或输入)的字段宽度，通常用于控制输出对齐，即输出格式化
